# 🏋️ Gym Tracker

Aplicación web desarrollada con Angular para usuarios de gimnasio que buscan **organizar, crear y seguir sus entrenamientos semanales** de forma sencilla e intuitiva.

## 😉 Características

- ✅ Crear entrenamientos personalizados
- ⏱️ Iniciar y registrar un entrenamiento 
- 📆 Vista semanal con planificación de sesiones
- 📝 Registro de ejercicios, series, repeticiones y cargas

## 🚀 Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/AdrianCB27/gym-tracker-frontend.git

2. Accede al proyecto
   ```bash
   cd gym-tracker-frontend

3. Instala las dependencias
   ```bash
   npm install
4. Cambia la dirección de la constante apiUrl del archivo src/environments/enviroment.ts a la dirección de tu backend (opcional si no quieres modificar el backend)
   
5.Inicia el servidor
   ```bash
   ng serve -o
